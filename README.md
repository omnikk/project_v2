# ТЕХНИЧЕСКОЕ ЗАДАНИЕ
## Разработка веб-ресурса администрирования крупной сети предприятий бьюти индустрии с расширенной системой интерактивных дашбордов

## 1. Основание для разработки

Разработка веб-приложения обусловлена необходимостью создания инструмента бизнес-аналитики (BI) для управления и анализа данных крупной сети салонов красоты с целью повышения эффективности принятия управленческих решений на основе данных.

## 2. Назначение разработки

Создание программного комплекса для администрирования сети салонов красоты с возможностью интерактивного анализа бизнес-данных, построения пользовательских дашбордов и визуализации ключевых показателей эффективности в режиме реального времени.

## 3. Цели разработки

- Создание BI-инструмента для анализа данных сети из 200 салонов красоты
- Реализация системы интерактивных дашбордов с возможностью конструирования виджетов
- Разработка модуля аналитики с фильтрацией по периодам, регионам, источникам записи
- Обеспечение работы с Big Data (3,8+ млн записей за 2024–2026 годы)
- Реализация микросервисной архитектуры с контейнеризацией

## 4. Требования к функциональным характеристикам

### 4.1. Модуль обзора (Overview)

- KPI-карточки: выручка, завершённые записи, отменённые записи, средний чек, конверсия, скидки, бонусы
- График выручки по месяцам за весь период
- Круговая диаграмма источников записей (web / iOS / Android / walk-in / phone)
- Глобальные фильтры: период дат, источник записи, регион, конкретный салон
- Экспорт данных в CSV

### 4.2. BI-конструктор дашбордов

- Создание и удаление именованных дашбордов
- Конструктор виджетов с выбором метрики, разбивки и типа визуализации
- Поддержка 5 типов графиков: линейный, столбчатый, круговой, KPI-карточка, таблица
- Поддержка 5 метрик: выручка, количество записей, средний чек, скидки, бонусы
- Поддержка 6 разбивок: по времени, источнику, салону, услуге, методу оплаты, дням недели
- Валидация допустимых комбинаций метрика/разбивка/тип графика
- Автоматическое обновление всех виджетов при изменении глобальных фильтров
- Сохранение конфигурации дашбордов в базе данных

### 4.3. Модуль аналитики салонов

- Рейтинговая таблица 200 салонов с сортировкой по выручке, количеству записей, среднему чеку
- Фильтрация по формату салона (премиум / стандарт / эконом)
- Экспорт сводной таблицы салонов в CSV

### 4.4. Модуль аналитики услуг

- Топ услуг по выручке с прогресс-барами
- Категоризация услуг (волосы / ногти / лицо / тело / брови)
- Экспорт данных по услугам в CSV

### 4.5. Система фильтрации

- Глобальные фильтры применяются ко всем страницам и виджетам одновременно
- Фильтры: период дат (2024–2026), источник записи, регион (10 регионов), салон (200 салонов)
- Сброс всех фильтров одной кнопкой

## 5. Требования к надежности

## 3. ОПИСАНИЕ ЛОГИЧЕСКОЙ СТРУКТУРЫ

**Архитектура:** Микросервисная архитектура с тремя независимыми сервисами.

### Микросервисы:

| Сервис | Порт | Роль | Docker |
|---|---|---|---|
| data-service | 8001 | Аналитические данные, Big Data | ✅ |
| dashboard-service | 8002 | Конфигурации дашбордов и виджетов | ✅ |
| frontend | 80 | React SPA + nginx reverse proxy | ✅ |

### Data Service — файлы:

| Файл | Роль |
|---|---|
| `database.py` | Подключение к SQLite, создание сессий |
| `models.py` | Модели: Region, Salon, Master, Client, Service, Appointment, DailySalonStat |
| `main.py` | REST API: аналитика, фильтры, экспорт CSV |
| `seed.py` | Генерация базовых данных (200 салонов, мастера, клиенты) |
| `seed_appointments.py` | Генерация 3,8 млн записей за 2024–2026 |

### Dashboard Service — файлы:

| Файл | Роль |
|---|---|
| `database.py` | Подключение к SQLite |
| `models.py` | Модели: Dashboard, Widget |
| `main.py` | CRUD дашбордов и виджетов |

### Frontend — структура:

| Папка/Файл | Роль |
|---|---|
| `src/api/index.js` | Централизованный слой запросов к сервисам |
| `src/context/FilterContext.jsx` | Глобальное состояние фильтров |
| `src/pages/Overview.jsx` | Страница обзора KPI |
| `src/pages/Dashboards.jsx` | Конструктор и просмотр дашбордов |
| `src/pages/Salons.jsx` | Рейтинг салонов |
| `src/pages/Services.jsx` | Аналитика услуг |
| `src/components/widgets/` | Компоненты виджетов (Chart, KPI, Constructor) |
| `src/components/layout/` | Sidebar, GlobalFilters, AppLayout |

### Схема базы данных (data-service):

Region   (1) → (N) Salon
Salon    (1) → (N) Master
Salon    (1) → (N) Appointment
Master   (1) → (N) Appointment
Client   (1) → (N) Appointment
Service  (1) → (N) Appointment

### Схема базы данных (dashboard-service):

## В данном проекте реализовано

### 1. База данных

**Что используется:** SQLite 3 + SQLAlchemy 2.0 (ORM)

**Две независимые БД:**

| БД | Сервис | Содержимое |
|---|---|---|
| `salon_data.db` | data-service | Бизнес-данные: салоны, мастера, записи |
| `dashboards.db` | dashboard-service | Конфигурации дашбордов и виджетов |

**Индексы для производительности:**
```sql
idx_apt_salon_year_month (salon_id, year, month)
idx_apt_start_time (start_time)
idx_apt_source (source)
idx_apt_status (status)
```

**Команды для пересоздания БД:**
```bash
cd data-service
rm salon_data.db
python seed.py
python seed_appointments.py  # занимает ~10 минут
```

### 2. REST API

**Data Service endpoints:**

| Endpoint | Описание |
|---|---|
| GET /api/filters/options | Справочники для фильтров |
| GET /api/analytics/kpi | KPI показатели |

| GET /api/analytics/by-source | По источникам записи |
| GET /api/analytics/by-salon | По салонам |
| GET /api/analytics/by-service | По услугам |
| GET /api/analytics/by-payment | По методам оплаты |
| GET /api/analytics/by-weekday | По дням недели |
| GET /api/analytics/discounts | Скидки и бонусы |
| GET /api/export/appointments | Экспорт записей CSV |
| GET /api/export/salons-summary | Экспорт салонов CSV |
| GET /api/export/services | Экспорт услуг CSV |

**Dashboard Service endpoints:**

| Endpoint | Описание |
|---|---|
| GET /api/dashboards | Список дашбордов |
